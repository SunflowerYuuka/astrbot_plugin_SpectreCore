# v2.4.0

- 修复 legacy 开启读空气却使用流式发送时不引用的问题：仅对本次请求关闭流式，完整判断 `<NO_RESPONSE>` 后由 AstrBot 装饰并发送，全局流式设置保持不变。
- 修复 model 模式遗漏 AstrBot 默认引用：无自主引用时按设置引用触发消息，已有引用不重复添加，群聊同步兼容 @ 发送人设置。
- 新增默认关闭的并发回复编排：规则门控后一次 JSON 决策/生成，支持指定 provider、并发上限与超时。
- 新增默认关闭的账号级发送队列：账号 token bucket、单群间隔、随机抖动、TTL、去重、优先级、容量限制和发送失败重试。
- 历史读写异步化，按聊天加锁并原子写入；直接发送成功后保存机器人历史。
- 修复 in-progress 生命周期，增加超时兜底和请求归属检查。
- legacy 继续使用原有 AstrBot 链路；model 模式使用临时提示词，不修改人格，不启用工具或流式输出。

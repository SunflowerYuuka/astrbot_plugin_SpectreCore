# v2.4.1

- **修复 legacy 读空气与流式冲突** - 开启读空气时，仅对本插件本次请求关闭流式发送；等待完整生成后判断 `<NO_RESPONSE>`，再由 AstrBot 添加引用并发送。全局流式设置保持不变，关闭读空气后沿用原来的流式选择。
- **修复 model 默认引用兼容** - 遵循 AstrBot「回复时引用发送人消息」设置，无自主引用时补上触发消息的引用，已有引用不重复添加。该兜底不依赖 `smart_quote` 开关，队列开启和关闭时均生效。
- **兼容群聊 @ 设置** - model 模式补上默认引用时，同时遵循「回复时 @ 发送人」设置；私聊不额外添加 @。
